The oath

Kadı answers on its own only when its conformal prediction set has exactly one label. Otherwise it escalates to the oracle. Under exchangeability, this keeps the share of decisions that disagree with the oracle at or below each court's target α. Adaptive conformal inference adjusts αt as traffic drifts. Random audits re-ask the oracle about local answers, so the agreement figure above is measured, not assumed.
